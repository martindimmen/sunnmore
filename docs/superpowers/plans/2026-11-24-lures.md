# Lure Blocks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add two placeable lure blocks: Glenns Plante (lures Glenn) and Treningsbenk (lures Jinith). Each in-game morning there is a 50% chance a friend visits his lure. Jinith also gets natural visits, like Glenn.

**Architecture:**
- **Visits:** `GlennVisits` becomes a shared `martidi.sunnmore.visits.FriendVisits`, driven by one `Friend` config per NPC: entity type, saved state attachment, lure POI type, command name.
- **Rules:** the pure numbers live in `VisitMath`, and are unit tested.
- **Lures:** points of interest, registered through Fabric's `PoiHelper`. The game finds them with `PoiManager.findClosest` near each player.
- **NPC side:** both NPCs implement a small `VisitingFriend` interface (set the visit length, say the arrival line).

**Tech Stack:** Minecraft 26.3, Fabric API 0.167.0+26.3 (object-builder `PoiHelper`, lifecycle, command, data-attachment), JUnit 5.

**Spec:** `docs/lures-design.md`

## Global Constraints
- **Glenn without a plant:** visits behave exactly as before (delay 24000, chance 25→75 by +25 per miss, an extra 1-in-3 roll, daytime only, 2-day stay, name tag keeps him).
- **Saved data:** Glenn's existing attachment id `sunnmore:glenn_visits` keeps working. New fields are optional with defaults.
- **Text:** new lines are in Sunnmørsk; use the `sunnmorsk` skill, with keys in `en_us.json`.
- **Lure rule:** 50% per in-game day, rolled in the first daytime check of a new day. The lure must be within 64 blocks of an online player. The spawn spot is within 4 blocks of the lure.

## Review Focus
1. **Lure indoors:** a plant under a roof must not spawn Glenn on the roof. Search standing spots around the lure itself, at y-2 to y+2, not by heightmap → `VisitMath` spot ordering test plus a manual check.
2. **Friend already around:** a friend who is already visiting, or a name-tagged resident near the lure, must not cause a second copy → `isStillVisiting` checks loaded visitors; a resident does not block.
3. **Night:** no lure arrivals at night; the day's roll waits for daylight → `lureRollWaitsForDay`.
4. **Old saves:** the Glenn visit state saved before this change must load, with lastLureDay defaulting to "never" → codec `optionalFieldOf`.
5. **Fight interruptions:** a visiting Jinith must not vanish in the middle of a fight. He leaves only when calm, not angry, scaring or flexing.
